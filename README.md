# Revision Tracker

Revision Tracker is a full-stack MERN application designed to help students organize their study sessions and maintain an effective revision schedule using the principles of spaced repetition. The application aims to reduce forgetting by automatically planning future revisions and providing insights into study progress.

## Project Status

**Current Phase:** Planning & System Design

This repository is currently under active development. The project is being built following a structured software development process, beginning with planning and documentation before implementation.

---

## Problem Statement

Students often study consistently but struggle to revise topics at the right time. As a result, knowledge retention decreases over time.

Revision Tracker addresses this problem by allowing users to record study sessions, automatically generate revision schedules, track progress, and build a consistent revision habit.

---

## Objectives

- Help users organize subjects and study topics.
- Automatically generate revision schedules.
- Track daily and weekly revision progress.
- Monitor study consistency through streaks and analytics.
- Provide a scalable platform for future learning features.
